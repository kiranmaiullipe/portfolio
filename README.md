A responsive editorial-style portfolio built with HTML, CSS and vanilla JavaScript.

## Design
- Forest & Mocha colour palette
- Editorial typography (Playfair Display + DM Sans)
- Responsive desktop, tablet and mobile layouts
- Reduced-motion support, keyboard-friendly navigation and semantic sections

## Run locally
1. Extract the ZIP file.
2. Open the folder.
3. Double-click `index.html`, or use VS Code Live Server for a local preview.
4. The Google Fonts connection requires internet access; system serif/sans-serif fallbacks are included.

## Contact form
The contact form uses a `mailto:` link to prepare an email to `kiranmaiulipe@gmail.com`. It does not transmit form data to a server. For server-side submissions, connect a form service or backend before deployment.

## Before publishing
- Confirm the wording and status of each project.
- Add your professional photo only when you choose to provide it; the current design intentionally uses typography rather than a blank photo slot.
- Add your resume PDF when ready. The current resume call-to-action opens an email request instead of linking to a fictional file.
- Add missing certificate scans only when available. The current page lists the five selected credentials and shows the two supplied certificate images.
- Verify the DRDL internship and Agentic AI credential details before adding dates or issuing organizations.

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `vlipa-kiranmai-portfolio`.
2. Upload the contents of this folder to the repository root (not the ZIP itself).
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish. The public URL will appear in the Pages settings; it will typically look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
7. To update the site, edit the files locally and push the updated files to the same repository. GitHub Pages will publish the changes.
